# 项目概览

**事实**：这是企业数据平台助手，通过 CLI、HTTP 或 Python Runtime 接收请求，用 LangGraph 状态图连接意图路由、业务节点和 37 个平台工具。默认走规则路由和内存平台适配器；可配置 LLM 路由和 HTTP 平台适配器。主要代码在 `src/data_agent/`。

**事实**：执行图从 `prepare → route` 开始，按单一意图进入专用节点，最后经 `finalize → END`。查询、权限和工单状态有少量条件分支。权限申请可通过 `interrupt` 暂停，调用 `resume` 继续。

**事实**：平台负责表、权限、SQL 和查询事实；节点负责调工具和格式化响应。默认 `MemorySaver` 按 `session_id` 留存 State。代码没有向量库或独立长期记忆模块。

**推断**：项目偏向确定性业务编排，不是由 LLM 自主反复选择工具的通用 ReAct Agent。意图路由可用 LLM，但具体业务节点中的工具顺序由 Python 代码决定。

**未知**：仓库未提供真实线上事故记录或生产部署配置，因此不能把测试覆盖的失败场景说成已经发生过的线上事故。
